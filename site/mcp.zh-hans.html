通过 AI 助手询问图谱

MCP 服务器及其连接方式

VisualNeuroscience.AI 通过一台自己的小型服务器，在你选用的 AI 中回答问题——任何支持模型上下文协议（Model Context Protocol）的助手都可以。你可以询问某个脑区的功能、某个布罗德曼分区的位置及其相邻分区、某种受体的密度，或大脑网络在某种状态下如何重组；回答取自与这些页面相同的数据，并附有链接，可在这里打开同一视图。询问图谱无需账户，也无需密钥；只有当你希望助手读取或保存你自己的模型时，才需要登录。

地址

https://mcp.visualneuroscience.ai/

仅此而已：服务器在该地址上通过可流式 HTTP 传输提供 MCP 服务，斜杠后无需任何路径。在浏览器中打开它会列出所有工具；/health 会返回 ok。

连接方法

  • 在助手的应用或网站中。打开用于添加连接器、应用或 MCP 服务器的设置，用上述地址添加一个自定义项；如果它询问身份验证方式，请选择在需要时登录。之后图谱工具即可直接使用，账户工具会在首次使用时请你登录。有些助手把自定义服务器放在设置的开发者模式中，大多数助手允许你在每次对话中开启连接器。
  • 团队或组织。如果由所有者统一管理连接器，只需由其用上述地址添加一次，其他人再在各自的设置中连接即可。
  • 在编程助手中。通过该助手添加 MCP 服务器的命令或其 MCP 配置文件，把它添加为名为 visualneuroscience 的 HTTP 服务器，并填入上述地址。

五个图谱工具都是只读的，并在注解中注明，因此助手调用它们时无需你逐一批准；助手通过它们进行的任何操作都不会改变任何内容，无论在这里还是别处。另有四个工具作用于你自己的账户，首次用到时会请你登录：如果由所有者为组织添加连接器，应将其身份验证设为在需要时登录。

五个工具

search_brain
按名称、编号或功能同时搜索所有内容——AAL 脑区、布罗德曼分区、网络节点和受体结构——返回每个匹配项的功能，并附上进入图谱的链接。“大脑的哪些部分负责识别面孔？”
region_info
某个 AAL 脑区的功能、它属于大脑的哪一层、是否有其受体密度图表，以及一个链接，可在扫描图像的三个平面和三维视图中高亮显示该脑区。“前扣带回有什么功能？”
brodmann_area
按编号查询某个布罗德曼分区：其解剖名称、所在脑叶与功能、相关的注意事项，以及根据图谱体数据测得的相邻分区。“布罗德曼 44 区是什么？与哪些分区相邻？”
receptor_density
某个脑区的受体密度，或某种受体在 45 个大脑区域中密度最高的位置；数据来自两个分开呈现的来源：在体 PET（以各受体在其自身密度最高区域中的占比表示）和离体放射自显影（以 fmol/mg 蛋白表示）。每条回答都注明示踪剂、样本和引用文献。“D2 受体在哪里密度最高？”“海马中哪些受体密度最高？”
brain_state
大脑的大尺度网络在六种状态之一（心流、静息、专注、威胁、奖赏追求和冥想）下如何重组：哪些耦合增强、哪些减弱，以及每种综合描述所依据的文献。不指定状态调用时，会列出这六种状态。“处于心流状态时大脑会发生什么变化？”

使用你的账户

如果你有 VisualNeuroscience.AI 账户，在你允许之后，助手就可以使用它。助手首次用到这四个工具之一时，会显示一个“连接”按钮；点按后会打开本站的一个页面，你可以像在应用中一样登录并点按“允许”，助手随后会从中断处继续。助手永远看不到你的密码；当你在助手中退出登录、修改密码或删除账户时，它获得的密钥即会失效。

my_account
当前登录的身份：你的用户名、大学和电子邮箱。“我当前连接的是哪个账户？”
list_models
保存在你账户中的三维脑区图谱模型，每个都注明其高亮内容，并附有打开它的链接。“我保存了哪些模型？”
load_model
按名称打开一个已保存的模型：其包含的脑区，以及在扫描图像上高亮显示它的链接。“打开我的记忆环路模型。”
save_model
根据一组脑区保存一个新模型，它随后会出现在所有登录该账户的设备上应用的“已保存模型”中。它只会新建：已被使用的名称会被拒绝，因此助手永远不会覆盖或删除你的成果。“把海马、左侧杏仁核和丘脑保存为一个名为‘记忆环路’的模型。”

如需撤销访问权限，请在助手中移除或断开该连接器。本服务器不保存任何与连接有关的信息：密钥由助手持有，且该密钥由 Firebase 签发，也就是让你登录应用的同一服务。

回答的来源

服务器的数据由这些页面所用的同一批文件生成，因此不会与页面不一致：MNI152 模板上的 AAL-116 分区图谱、MRIcron 图谱中的 41 个布罗德曼分区及其测得的边界、Hansen 等人 2022 年汇编的 PET 图谱（CC BY-NC-SA 4.0）与 Zilles 和 Palomero-Gallagher 2017 年的放射自显影（CC BY 4.0）所提供的受体密度，以及六种网络状态及其来源。与这些页面一样，它是教育参考资料，不构成医疗建议；每条关于受体的回答都会说明其依据的示踪剂和样本。

它保存什么

什么都不保存。服务器没有自己的账户，也不保存状态；除其运行平台短期保留的运行日志外（详见隐私页面），不记录你的任何问题。连接账户后，助手读取或写入的已保存模型与应用存放在同一位置，即你的账户下，服务器只做转递，不保留副本。你在助手中输入的内容受该助手自身的隐私政策约束。

开发者说明

它是一个没有任何依赖的 Cloudflare Worker，通过 POST 使用 JSON-RPC 2.0 通信。登录采用带 PKCE 的 OAuth 2.1，按标准方式发现（/.well-known/oauth-protected-resource 和 /.well-known/oauth-authorization-server），客户端可动态注册，或通过客户端 ID 元数据文档注册；不带令牌调用账户工具时，会返回 401 及发起授权的质询。不借助助手也可以直接调用这些工具：

curl -s https://mcp.visualneuroscience.ai/ -X POST \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
